# Preferencias de colaboración del propietario

- Abrir páginas de servicios externos en el navegador externo del usuario. No usar la vista previa o navegador integrado de Codex.
- El usuario mantiene sus cuentas abiertas en otro navegador. No solicitar acceso a las cuentas ni entregar enlaces de acceso salvo que el usuario los pida explícitamente.
- Antes de cualquier acción importante, solicitar autorización explícita y explicar brevemente su efecto.
- Se consideran acciones importantes: reactivar o pausar servicios, modificar configuraciones cloud, crear o reemplazar credenciales, cambiar permisos, generar costos, enviar correos o mensajes, eliminar datos, hacer `git push`, desplegar o publicar.
- Las inspecciones de solo lectura, compilaciones y pruebas locales que no modifican servicios externos pueden ejecutarse sin una autorización adicional.
- No desplegar ni publicar cambios hasta que el propietario apruebe expresamente el paso de producción.
